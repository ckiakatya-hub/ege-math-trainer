Проверенная базовая теория

Формулы не являются «авторскими». Это стандартные математические тождества, определения и теоремы школьного курса. Условия применения указаны там, где они существенны.

Квадратное уравнение ax²+bx+c=0, a≠0: D=b²−4ac; x=(-b±√D)/(2a) при D≥0.
Теорема Пифагора для прямоугольного треугольника: c²=a²+b², где c — гипотенуза.
Скалярное произведение: a·b=|a||b|cosα. В координатах на плоскости: a·b=ax·bx+ay·by.
Вероятность равновозможных исходов: P(A)=m/n.
Для несовместимых событий: P(A∪B)=P(A)+P(B). В общем случае: P(A∪B)=P(A)+P(B)−P(A∩B).
Математическое ожидание дискретной случайной величины: E(X)=Σ xi·pi, где Σpi=1.
Дисперсия: D(X)=E(X²)−[E(X)]². Стандартное отклонение: σ(X)=√D(X).
Производная: (xⁿ)'=n·xⁿ⁻¹ для целых n и там, где функция определена; (sin x)'=cos x; (cos x)'=−sin x; (eˣ)'=eˣ; (ln x)'=1/x при x>0.
Производная суммы: (f+g)'=f'+g'; произведения: (fg)'=f'g+fg'; частного: (f/g)'=(f'g−fg')/g² при g≠0.
Первообразная: F'(x)=f(x). Если f непрерывна на [a,b], то ∫ₐᵇf(x)dx=F(b)−F(a).
Площадь треугольника: S=(1/2)ah, где h — высота к стороне a; также S=(1/2)ab sinγ.
Объём призмы: V=Sосн·h. Объём прямоугольного параллелепипеда: V=abc.
Логарифм: logₐb=c ⇔ aᶜ=b, при a>0, a≠1, b>0.
Свойства логарифмов применяются при допустимых значениях аргументов: logₐ(xy)=logₐx+logₐy при x>0,y>0; logₐ(x/y)=logₐx−logₐy при x>0,y>0.
Неравенство Коши для x>0: x+A²/x≥2A, A>0. Равенство при x=A.
Для арифметической прогрессии: aₙ=a₁+(n−1)d; Sₙ=n(a₁+aₙ)/2.
